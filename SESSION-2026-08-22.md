### 3. Hero Animation Fix (`src/animations/hero.ts`)

**Problem:** Elements flashed on page load before GSAP animation started.

**Solution:**
1. CSS hides elements initially: `.hero-badge, .hero-title-line, .hero-description, .hero-btn { opacity: 0; }`
2. Title text scrambled immediately in `startAnimation()` before any setTimeout
3. GSAP timeline uses explicit time positions for sequencing:
   - Position 0: Badge + title fade in
   - Position `totalScrambleTime + 0.1`: Description fades in
   - Position after description: Buttons fade in

**Animation sequence:**
1. Badge (fade in)
2. Title lines (scramble text + fade in)
3. Description words (staggered fade in)
4. Buttons (fade in)
